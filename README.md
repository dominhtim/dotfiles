# dotfiles

Shell (fish or zsh), git, tmux and Neovim config, managed with
[chezmoi](https://www.chezmoi.io/).

Just the dotfiles — no package installs, no system provisioning. That lives
in [workstation-setup](https://github.com/dominhtim/workstation-setup), which
provisions a fresh machine and applies this repo as its last step. This repo
works on its own and doesn't know that one exists.

## Quick start

```bash
chezmoi init --apply dominhtim/dotfiles
```

You'll be asked for your git name and email once. chezmoi stores the answers
in `~/.config/chezmoi/chezmoi.toml` and won't ask again on this machine.

Only one shell's config is applied, picked by `shell` in that file: `zsh`
unless set otherwise (`workstation-setup` sets it from its `login_shell`).
To switch by hand, set `shell = "fish"` under `[data]` and run
`chezmoi apply`.

Don't have chezmoi? [Install it](https://www.chezmoi.io/install/) first, or
use `workstation-setup`, which installs it as part of setting up the machine.

Open `nvim` once afterwards and let lazy.nvim install the plugins, then
restart it.

## Layout

```
dotfiles/
├── .chezmoi.toml.tmpl      ← prompts for name/email on first `chezmoi init`
├── .chezmoiignore          ← skips the shell that isn't chosen
├── dot_zshrc.tmpl          ← oh-my-zsh, powerlevel10k, fzf, history, aliases
├── dot_gitconfig.tmpl
├── dot_gitignore_global
├── dot_p10k.zsh            ← generated by `p10k configure`
├── dot_tmux.conf           ← Ctrl-a prefix, vi copy mode, mouse on
├── dot_config/fish/        ← config.fish: aliases, fzf, clipboard
└── dot_config/nvim/        ← lazy.nvim, LSP via Mason, Telescope, Treesitter
```

Filenames encode their destination: `dot_zshrc` → `~/.zshrc`,
`dot_config/nvim/init.lua` → `~/.config/nvim/init.lua`. A `.tmpl` suffix means
the file is a Go template, rendered from the data in `chezmoi.toml`.

## Editing

```bash
chezmoi edit ~/.zshrc     # opens the source file in this repo
chezmoi diff              # what would change in $HOME
chezmoi apply             # write it out
chezmoi cd                # drop into the repo (aliased to `dotfiles`)
```

`chezmoi edit` opens the *source*, not the copy in your home directory —
editing the copy directly gets it overwritten on the next apply.

After committing and pushing, `chezmoi update` on another machine pulls and
applies in one step.

## Per-machine differences

Two options, and the choice matters:

**Templating**, for real, known-in-advance differences — identity,
OS-specific paths. `dot_zshrc.tmpl` has a worked example:

```
{{- if eq .chezmoi.os "darwin" }}
alias pbc='pbcopy'
{{- else }}
alias pbc='xclip -selection clipboard'   # wl-copy under Wayland
{{- end }}
```

**`~/.zshrc.local`** or **`~/.config/fish/local.fish`**, for one-off tweaks
you don't want tracked. Each is sourced at the end of its shell's config and
stays outside chezmoi and git entirely.

## What's configured

**fish** — the same aliases as zsh, fzf bound to Ctrl+R (history), Ctrl+T
(files) and Alt+C (cd), `nvim` as `$EDITOR`, no greeting. Autosuggestions,
syntax highlighting and history are fish's own.

**zsh** — oh-my-zsh with powerlevel10k, `zsh-autosuggestions` and
`zsh-syntax-highlighting`; fzf bound to Ctrl+R (history), Ctrl+T (files) and
`**` completion; 50k-line shared history with dedup; `nvim` as `$EDITOR`.

**Neovim** — lazy.nvim, native LSP with servers installed by Mason
(`lua_ls`, `pyright`, `bashls`), nvim-cmp completion, Telescope
(`<leader>ff` files, `<leader>fg` grep, `<leader>fb` buffers), Treesitter,
gitsigns, which-key, gruvbox. Leader is space. **Requires Neovim >= 0.11.**

**tmux** — Ctrl-a prefix, mouse on, vi-style copy mode, splits that keep the
current pane's directory, `prefix r` to reload.

**git** — `main` as the default branch, rebase on pull, `autoSetupRemote` on
push, `diff3` conflict style, and short aliases (`st`, `lg`, `amend`, `undo`).

## Troubleshooting

**The prompt is garbled boxes.** Powerlevel10k's icons need a
[Nerd Font](https://www.nerdfonts.com/) installed on whatever you're
*looking at the terminal with*. Connecting to a VM from Windows Terminal
means installing MesloLGS NF on Windows and setting it in the Windows
Terminal profile — installing a font inside the VM does nothing.

The Neovim statusline is deliberately configured not to need one.

**`p10k configure`** regenerates `~/.p10k.zsh`. Run `chezmoi add ~/.p10k.zsh`
afterwards to pull the result back into this repo.

**LSP errors on startup** usually mean Neovim is older than 0.11.

## Uninstall

```bash
chezmoi purge
```

Removes chezmoi's config and its clone of this repo. Your dotfiles are real
files at that point, not symlinks — delete them by hand if you want them gone.
